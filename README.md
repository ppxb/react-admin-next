# React Admin Next

基于 React + Antd 搭建的后台管理系统。使用 React 19、Antd 6、Vite 8、Tanstanck-Router、Zustand、Typescript、Tailwindcss V4开发。

代码简洁规范，符合最佳实践。致力打造标准的后台模版，可直接用于生产环境开发。后期拟接入 LLMS 以及相应的 SKILL 以满足 AI 接入。

> [!IMPORTANT]
> 项目处于快速开发中。

## 快速开始

```bash

$ git clone https://github.com/ppxb/react-admin-next.git

$ cd react-admin-next && code .
$ pnpm install
$ pnpm run dev
```
